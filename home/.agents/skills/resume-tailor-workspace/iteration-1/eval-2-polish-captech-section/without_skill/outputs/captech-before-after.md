# CapTech Section Polish — Before/After

Scope: only the 7 bullets under "Manager – Data & AI Consulting | CapTech Consulting". No facts, metrics, or claims were added; all edits are grammar, word choice, and tightening. Everything else in the resume is untouched.

## Bullet 1
**Before:** Designated internal Data Engineering Lead for the firm's Databricks practice, accountable for technical standards, internal enablement, and POC architecture across the practice.
**After:** Appointed Data Engineering Lead for the firm's Databricks practice, owning technical standards, internal enablement, and POC architecture across the practice.
**Why:** "Designated internal" read as passive filler; "Appointed ... owning" is a stronger verb pair.

## Bullet 2
**Before:** Built an LLM-assisted generative AI migration framework automating schema translation and pipeline conversion from Snowflake, Teradata, and SQL Server to a modern lakehouse, materially reducing migration delivery time.
**After:** Built a generative AI migration framework that automates schema translation and pipeline conversion from Snowflake, Teradata, and SQL Server to a modern lakehouse, materially reducing migration delivery time.
**Why:** "LLM-assisted generative AI" was redundant; kept "generative AI" for keyword coverage.

## Bullet 3
**Before:** Led data architecture for top-5 QSR supply chain engagement: designed medallion architecture on AWS, implemented dbt for orchestration and the semantic layer, and established data governance from greenfield.
**After:** Led data architecture for a top-5 QSR's supply chain engagement: designed a greenfield medallion lakehouse on AWS, implemented dbt for orchestration and the semantic layer, and established data governance standards.
**Why:** Removed "architecture ... architecture" repetition; "from greenfield" was ungrammatical, moved greenfield to where it reads naturally.

## Bullet 4 (largest fix)
**Before:** Lead Architect for fortune 500 financial sector client: Implementation strategy for data architecture design and integration of newly acquired entity data. Ensuring historical and new data integrated efficiently.
**After:** Served as Lead Architect for a Fortune 500 financial services client, defining the data architecture and implementation strategy for integrating a newly acquired entity's data and unifying historical and incoming data on the enterprise platform.
**Why:** This bullet had sentence fragments, lowercase "fortune 500", and a dangling "Ensuring..." clause. Rewritten as one grammatical sentence with a lead verb.

## Bullet 5
**Before:** Built a reusable Infrastructure as Code deployment accelerator (Terraform and Bicep) for end-to-end lakehouse platforms on AWS and Azure with governance and DataOps pipelines included.
**After:** Built a reusable Infrastructure as Code accelerator (Terraform and Bicep) that deploys end-to-end lakehouse platforms on AWS and Azure with governance and DataOps pipelines built in.
**Why:** "deployment accelerator ... included" was clunky; active "that deploys ... built in" is tighter.

## Bullet 6
**Before:** Managed an onshore/offshore team executing an on-prem to AWS cloud migration for a top client, delivered within a 6-month timeline.
**After:** Managed an onshore/offshore engineering team through an on-prem to AWS migration for a flagship client, delivering the full migration within six months.
**Why:** Fixed the dangling "delivered" (grammatically it modified the client, not the work); "a top client" → "a flagship client".

## Bullet 7
**Before:** Delivered internal technical workshops and contributed to pre-sales solutioning with architecture artifacts, demos, and SOW scope validation.
**After:** Delivered internal technical workshops and supported pre-sales solutioning with architecture artifacts, demos, and SOW scope validation.
**Why:** Minor: "contributed to" is weaker phrasing; otherwise the bullet was already solid.
